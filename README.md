## 1. المشكلة

النماذج اللغوية العامة تجيب عن الأسئلة الفقهية **بثقة، لكن بلا مصدر**، وأحيانًا بإجابة خاطئة، ولا تقول «لا أعلم» حين لا تملك مرجعًا. فلا يستطيع السائل التحقق من الحكم أو الرجوع إلى أصله.

## 2. الحل

FiqhQA طبقة أمان معرفية فوق النموذج اللغوي:

- **نص:** يجيب من نصوص المرجع المسترجَعة وحدها، لا من ذاكرة النموذج.
- **مصدر:** يختم كل حكم برقم مرجعه (الكتاب والباب ورقم السؤال) ليتحقق السائل بنفسه.
- **امتناع وإحالة:** إن ضعف السند أو لم تتضمن النصوص الجواب، لا يخمّن، بل يمتنع ويحيل إلى أهل العلم.

**المرجع:** «الأسئلة والأجوبة الفقهية» للشيخ عبدالعزيز بن محمد السلمان (المكتبة الشاملة)، حُوِّل إلى **1,140** زوج سؤال وجواب، كل منها موسوم بكتابه وبابه ومرجعه.

## 3. آلية العمل

```
سؤال المستخدم
   │  تطبيع عربي (حذف التشكيل، توحيد الألف والتاء المربوطة)
   ├──► BM25 ── مطابقة المصطلح الفقهي (أعلى 30)
   └──► E5 + FAISS ── مطابقة المعنى (أعلى 30)
            │
        دمج RRF (k = 60)
            │
   إعادة ترتيب عربية (arabic-reranker) ← أفضل 5 نصوص
            │
   درجة الصلة أقل من العتبة المعايَرة؟ ──► امتناع وإحالة إلى المختص
            │
   نموذج لغوي مقيَّد بالنصوص (Gemini أو SILMA)
            │
   لم يجد الجواب في النصوص؟ ──► امتناع وإحالة إلى المختص
            │
   إجابة + أرقام المراجع [n] + الكتاب والباب
```

## 4. النتائج

قياس آلي على مجموعة اختبار لم تدخل فهرس الاسترجاع، مقابل الإجابات المرجعية من الكتاب:

| النموذج | الإعداد | الهلوسة ↓ | التغطية ↑ | عدم الصلة ↓ | BERTScore ↑ |
|---|---|---|---|---|---|
| Gemini 2.5 Flash | النموذج وحده | 61.3% | 42.6% | 33.4% | 0.535 |
| Gemini 2.5 Flash | **FiqhQA** | **13.5%** | **88.8%** | **0%** | **0.890** |
| SILMA-Kashif-2B | النموذج وحده | 45.3% | 48.5% | 7.3% | 0.533 |
| SILMA-Kashif-2B | **FiqhQA** | **15.6%** | **86.0%** | **0%** | **0.605** |

**اختبار الامتناع (معايرة العتبة):** على 46 سؤال اختبار و15 سؤالًا خارج نطاق المرجع:
- **91%** من الأسئلة داخل النطاق أُجيبت بسند (42 من 46).
- **11 من 15** سؤالًا خارج النطاق رُفضت عند طبقة الاسترجاع، وما يتجاوزها يمرّ على امتناع النموذج نفسه.

يمكن إعادة القياس بالسكربت `eval/evaluate.py`.

## 5. التقنيات المستخدمة

| الطبقة | الأدوات |
|---|---|
| البيانات | المكتبة الشاملة، Python |
| البحث الهجين | BM25 (rank-bm25)، intfloat/multilingual-e5-base، FAISS |
| الدمج وإعادة الترتيب | Reciprocal Rank Fusion، oddadmix/arabic-reranker |
| التوليد | Gemini 2.5 Flash (API، مع بدائل تلقائية عند الانشغال)، SILMA-Kashif-2B-Instruct (محلي، مفتوح) |
| الخادم | FastAPI، Docker، Hugging Face Spaces |
| الواجهة | HTML / CSS / JavaScript على Hostinger، ومرشد صوتي «سند» عبر ElevenLabs |
| التقييم | BERTScore (AraBERT)، التغطية، الهلوسة، عدم الصلة؛ Google Colab |


## 7. التشغيل

**الموقع:** افتح `index.html`، أو شغّل `start-site-windows.bat` / `start-site-mac.command`. يتصل الموقع بالخادم المحدد في `script.js` (`API_URL`).

**الخادم:**
```bash
cd backend
pip install -r requirements.txt
export GEMINI_API_KEY=...            # مفتاحك الخاص، لا يُرفع إلى المستودع
export DATA_PATH=LastRAG_dataset.csv
export MIN_RERANK_SCORE=10           # عتبة الامتناع المعايَرة
uvicorn main:app --port 8000
```
- `GET /health` حالة الخادم والنماذج.
- `POST /ask` بالحقول `{question, model: gemini|silma, system: baseline|fiqhqa-rag}`.

> مجموعة البيانات ومفاتيح الـAPI غير مرفوعة إلى المستودع عمدًا؛ يحمّل الخادم البيانات من مستودع بيانات خاص، والمفاتيح محفوظة في إعدادات الاستضافة (انظر `SOURCES_AND_LICENSES.md`).

## 8. ما أُنجز خلال أيام التحدي (4–6 أكتوبر 2026)

خادم موحّد يشغّل الأنظمة الأربعة، ربط الموقع بالنماذج فعليًا، تحسين الاسترجاع (فهرسة السؤال والجواب، بادئات E5، إعادة ترتيب أفضل 5 نصوص)، الامتناع والإحالة بطبقتين مع معايرة العتبة، البدائل التلقائية لنموذج Gemini، النشر على Hugging Face وHostinger، المرشد الصوتي «سند»، وسكربت التقييم. التفاصيل ونسخة البداية في `SOURCES_AND_LICENSES.md`.
